# Hr-Attrition-Dashboard
## Project Summary
Performed end-to-end HR attrition analysis using Power BI to identify employee turnover patterns, high-risk workforce segments, and key factors associated with employee attrition. Analyzed 1,470 employees and 237 employee exits, resulting in an overall attrition rate of 16.1%, and built an interactive dashboard to support data-driven employee retention and workforce planning decisions.

## Problem Statement
- What is the overall employee attrition rate?
- Which departments have the highest attrition?
- Which salary bands have higher attrition rates?
- How does attrition vary across different age groups?
- How does employee attrition differ by gender?
- Does overtime have an association with higher employee attrition?
- How does business travel frequency relate to employee attrition?
- How does marital status vary across attrition rates?
- Which employee segments should HR prioritize for retention initiatives?

## Dataset used
- <a href="https://github.com/ShivamAnalyst/Hr-Attrition-Dashboard/blob/main/HR-Employee-Attrition.csv">Hr Attrition Data</a>

## Tools and Technologies Used
- Microsoft Power BI – Interactive dashboard development, KPI cards, charts, tables, slicers, and business-focused visualizations.
- Power Query – Data cleaning, transformation, column standardization, and preparation of HR data for analysis.
- DAX (Data Analysis Expressions) – Created measures and calculated metrics for headcount, employee exits, and attrition rate.
- Data Visualization & Analytics Techniques – Attrition trend analysis, workforce segmentation, comparative analysis, and KPI-driven reporting.
